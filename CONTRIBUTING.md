# Contributing

SPDX-License-Identifier: Apache-2.0

This preview accepts focused changes that preserve the raw-payload boundary, closed contracts, synthetic-only examples, and honest non-claims.

Contributors certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/) by adding a `Signed-off-by` line to each commit. Do not contribute employer-confidential material, real patient data, licensed standards content, terminology, validator packages, model weights, generated model output containing payload values, or production evidence.

Run `npm run check` before opening a pull request. A capability claim must be backed by an executable test and must describe only what that test establishes.
